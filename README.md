# ScrambleFarm

農業 × ハイテンポアクション × ローグライク × 2.5次元

## 開発環境

- Unity
- C#
- GitHub

## ゲーム概要

15分間のスコアアタックゲームです。

敵モンスターを倒したり、作物を収穫することでスコアを獲得できます。

スコアはランキング形式で保存されます。

ゲームオーバーになった場合でも、その時点で獲得したスコアがランキングに反映されます。

ゲーム開始10分後にはボスが出現します。

## 制作目的

2026年11月末ごろに開催される、大学の文化祭での展示を目標としています。

特に、「操作していて気持ちいいアクション」を重点的に制作しています。
